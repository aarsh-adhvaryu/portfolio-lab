# E2 — Event layer (index)

E2 is four separate experiments, each with its own charter and each judged by
`GATE.md`. Run sequentially: E2-A, E2-B, E2-C, E2-D.

| charter | one-line rule | data starts |
|---|---|---|
| `E2-A.md` red flags | exclude/exit names with a distress announcement in 12 months | 2010 |
| `E2-B.md` shock graph | cap portfolio beta to any macro shock at 1.5× the index's | 2004 (VIX 2009) |
| `E2-C.md` regime input | VIX + GDELT tone composite as extra RISK_OFF trigger | 2015 |
| `E2-D.md` positioning | exclude names with net promoter/insider selling > 1% | 2010 |

Data collection for all four runs daily from now. Backfills (BSE 2010, GDELT
BigQuery, shareholding patterns, PIT) start after E1's first sweep and must be
complete before each charter's first run.
